# 使用六轨预制现代自然声景

状态：采纳。取代 ADR 0005 与 ADR 0006 的分层播放模型。

正式音频采用晨雾、云海、静水三个主题、各两个变体的固定六轨顺序。音乐、自然环境声与极少量尺八气息在发布前完成混音，运行时不再组合古琴主层、环境层和稀疏点缀层。这避免东方古典与宗教色彩过强，也让响度、署名和失败处理都以一个成品为边界。

每个 `AudioAsset` 的角色统一为 `soundscape`，以 `theme`、`variant`、双语标题及 `sources[]` 描述。只接受 CC0、公有领域或 CC BY 来源；成品以固定版 `ffmpeg-static` 生成 44.1 kHz 立体声 MP3，目标约 −24 LUFS、峰值不高于 −2 dBTP、每档小于 12 MiB，并保存处理说明、文件大小与 SHA-256。

播放器使用两个原生 `<audio>` deck。首次用户手势前两者均不设置 `src`；自动衔接为 6 秒，手动换景为 1.8 秒，使用等功率增益曲线。界面只提供播放／暂停、上一／下一景、当前声景、静音与单一音量。默认音量为 `0.32`，v2 偏好只保存曲目、音量与静音；从 v1 首次迁移时只保留旧静音并把旧主音量限制在 `0.32`。

页面进入后台立即暂停且不自动恢复；Astro ClientRouter 站内导航保留播放器。单轨失败时循环跳过，六轨全部失败才停止并显示双语状态。暂停交叉淡接时保留当时较响的 deck，并清除另一方。
